# Report fonts

Open metric-compatible substitutes used by the browser PDF writer (pdfmake) so reports keep the
insurers' layout metrics without shipping Microsoft fonts.

| Layout font | File family | Licence | Source |
|---|---|---|---|
| Calibri | Carlito | SIL OFL 1.1 (`Carlito-OFL.txt`) | github.com/google/fonts `ofl/carlito` |
| Cambria | Caladea | SIL OFL 1.1 (`Caladea-OFL.txt`; the Google Fonts release is OFL) | github.com/google/fonts `ofl/caladea` |
| Arial | Liberation Sans 2.1.5 | SIL OFL 1.1 (`LiberationSans-LICENSE.txt`) | github.com/liberationfonts/liberation-fonts |

Downloaded 2026-11-18. Regular, Bold, Italic and BoldItalic of each.
