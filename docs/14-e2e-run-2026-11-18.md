## Gaps (open)

### Blocking the workflow

1. **No way to complete a field task.** The field app has no "task done" action and there is no office RPC; approval requires no open task. In the run the two tasks were completed with the service role. Needs a field-app action (and/or `complete_field_task` for the office, the known DB gap). **Resolved 2026-11-19:** `complete_field_task` (operator in the app: thread menu "Mark task done"; office: "Mark complete" on `/tasks/[id]`), migration `20261119100000_task_complete_case_close.sql`.
2. **Report sender (8.2) does not exist.** `request_report_send` queues rows and `_shared/send` builds the mail, but nothing calls `claim_report_send`; email submissions may only be recorded by the sender, so an email insurer case cannot reach `submitted` except as channel `other`.
3. **No pipeline worker (D38)** and **no OCR engine**: labels need the worker (here Claude by hand); OCR / field suggestions never run, so tap-to-fill and number suggestions are empty.
4. **No close action** after the insurer's acknowledgement (no RPC moves `submitted` → `closed`). **Resolved 2026-11-19:** `close_case` ("Close case…" on `/submissions`; P7), same migration.

### Field app

5. **Composer overflow:** with ~13+ attached files the file list pushes the caption box and Send off-screen and does not scroll — the operator cannot send. Worked around by removing files and sending twice.
6. **Thread does not refresh after delivery:** the sent message disappears from the thread when it leaves the outbox and shows again only after reopening the case (no refetch / realtime on own messages).
7. Sent messages show **no file thumbnails, count or ✓/✓✓ ticks** in the thread.
8. **Task instructions and location are never shown** to the operator (only the title in the system message).
9. The operator's **own message raises the unread badge** on the case list.
10. Gallery files arrive with picker names (`1000243251.jpg`), not the album file names.

### Intake

11. **Dates stay in the insurer's format** (`17-OCT-2026`, `27-Sep-2026 12:40`) while the report workspace validates ISO dates/datetimes, so those intake fields show as invalid until retyped.
12. Investigation points are read from the **text/plain part**; a mail whose plain part is a stub loses them (real Gmail/Outlook mails carry a full plain part; HTML fallback would be safer). The block also absorbs the following line ("…IDV.Please ensure your report is comprehensive.").
13. **THEFT has no template** (sent to review; nothing to confirm it into).
14. Insurer data quirks pass through unchecked (IndusInd vehicle no. `NEW___`, claim-form loss year 2027); fine for review, worth a format warning.

### Reports

15. **Letterhead band, logo and seal are never supplied** (`runtime: true` assets; nothing fills `ReportData.assets`), so every report prints placeholder boxes there.
16. **A photo placed in a section the layout does not print is dropped silently** (not listed as unplaced). ICICI: the "insured holding written statement" photos go to `insured` (first section with `insured_photo`), which the ICICI layout does not print. Suggest a loader check: every section with categories must be printed by the layout, or placement should prefer printed sections.
17. Checklist / section counts include **insurer attachments**, so an operator's item can tick from a file the insurer sent (e.g. DL copy).
18. Statement blocks need the `---` format from the field help; a free-text statement prints entirely in the narrow name column.

### Deployment / process

19. Hosted functions drifted behind `main` unnoticed (evidence-view). Add a deploy check (compare function `updated_at` with the last commit touching it) or deploy from CI.
20. Templates loaded on hosted lag `config/templates` the same way; `templates:load` should be part of the deploy routine.
21. **Browser path not exercised by a person:** generation ran through the same `run.ts` from Node; the in-browser UI (worker, IndexedDB cache, Preview/Generate buttons) still needs a click-through, signed in by a human. Automation agents may not type passwords into `toyam-web.sledjesoftwares.workers.dev`; a host named like `staging`/`dev` would allow automated browser E2E with test logins.
22. Cancelling the probe task moved INV-2026-000002 to `office_review` with no field work done (cancel of the last open task advances the case) — check that this is intended.
